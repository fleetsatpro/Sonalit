# Intelligence Centre — Kenya Theatre QA

## Geography contract

A country-scoped intelligence row must have the requested ISO country code and independent textual country/place evidence. Feed configuration is never authoritative geography. Unsupported geography remains available globally but is excluded from country theatre reads.

## Language contract

Non-English event/observation text is translated to operational English at the intelligence response boundary when an AI provider is configured. Translation is cached by source-content hash, preserves names/numbers/uncertainty, and degrades to the source text if translation is unavailable.

## Visual contract

Primary titles, event text and analytical values use readable sizes. Severity remains semantically encoded while workspace navigation and panel families use diversified accent colors for rapid visual parsing.
